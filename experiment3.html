二、实验目的

实验一解决结构建模，实验二建立能带与态密度的判读方法，两次实验的对象都是无掺杂的理想晶体。本实验把模型推进到有掺杂、有空位的实际情形，计算对象也从能带转向光学性质。与本征晶体相比，掺杂与缺陷一方面破坏平移对称性，使原胞与空间群的描述不再成立；另一方面在禁带中引入能级，改变电子的跃迁路径。这些变化最终落在吸收谱上，表现为吸收边的位置与陡缓发生变化。

完成本实验后，应达到以下要求。

  1. 理解点缺陷的三种基本类型，即替位、空位、间隙，以及点缺陷对晶体平移对称性的破坏，能够说明建模时把空间群降为P1的原因。
  2. 掌握在超胞中实现替位掺杂与空位缺陷的操作方法，能够说明超胞规模与掺杂浓度之间的换算关系。
  3. 理解缺陷与掺杂结构必须先作几何优化再计算性质的原因，掌握CASTEP几何优化的主要设置与收敛判据。
  4. 理解复介电函数与吸收系数的关系，掌握光学性质计算的任务选择与输出函数设置。
  5. 掌握吸收谱的后处理，包括展宽参数、剪刀算符、偏振方向与横轴单位切换，能够判断曲线形态的变化来自物理原因还是参数设置。
  6. 掌握把计算结果导出为CSV数据文件的方法，理解直接截图不能用于定量分析的原因。
  7. 能够比较本征、掺杂、空位三种情形的吸收边位置与形状，说明差异的物理来源。

四、实验原理

4.1　点缺陷的类型与对称性的处理

晶体中的点缺陷分三类。替位缺陷是外来原子占据基体原子的格点，掺杂即属此类；空位是基体原子离开格点，留下空的格点；间隙缺陷是额外原子进入格点之间的空隙位置。三类缺陷都只涉及局部几个原子的位置变化，但在能带结构上的影响并不局部：替位原子与空位都会在禁带中引入能级，改变电子的跃迁能量。

建模时首先要处理对称性。软件默认按空间群的对称操作约束晶胞，晶胞内所有等价位置被视为同一种原子。若在保留原空间群的情况下把某一个格点的原子替换为杂质原子，软件会按对称性把这一替换复制到全部等价格点上，得到的不是单个杂质，而是一个按原晶胞周期排列的杂质阵列，与实验上低浓度掺杂的物理图像不符。Build菜单中的Symmetry→Make P1命令把空间群降为P1，即只保留平移操作、取消全部旋转与反映对称性，此后每个格点都成为独立位置，只改动其中一个不会波及其他格点。这是掺杂与缺陷建模必须先降对称性的原因。

降为P1取消的是对称性约束，不是周期性。计算仍在周期性边界条件下进行，超胞边界上的原子与其镜像原子成键，相邻超胞中的缺陷互为镜像。因此超胞必须足够大，使缺陷与其镜像之间的相互作用可以忽略；超胞过小会使带隙、吸收边出现明显的尺寸效应，这一现象在小超胞计算中很常见，报告中应说明所用超胞的原子数。

4.2　超胞规模与掺杂浓度

掺杂浓度由超胞规模决定。设惯用晶胞沿三个方向各重复N次，则超胞含8N³个原子，取代一个原子对应的原子分数浓度为1/(8N³)。2×2×2超胞含64个原子，单原子取代对应约1.56%的浓度，折合体浓度约7.8×10²⁰cm⁻³，远高于器件工艺中常见的掺杂浓度。要继续降低浓度，只能扩大超胞，而计算量随原子数近似按三次方增长。这一矛盾决定了第一性原理计算只适合描述高浓度掺杂或单个缺陷的局域性质，不能直接模拟低浓度掺杂的宏观电学行为。

讨论掺杂效应时，须在报告中写明超胞原子数与对应的浓度，不能只写掺杂元素的种类。同一元素在不同超胞中的效果可能相差很大，脱离浓度谈掺杂没有意义。

4.3　几何优化的必要性

理想的晶体结构中，原子位于对称性规定的位置，每个原子所受合力为零。引入杂质或空位后，缺陷周围的原子受力不再平衡：替位原子的半径与基体原子不同，空位使其近邻原子失去一个成键对象，两种情况都会使周围原子偏离原位，直至达到新的力平衡。这一过程称为结构弛豫，弛豫量在空位的第一近邻处可达晶格常数的百分之几。

未作优化的结构，键长与键角都偏离平衡值，由其计算得到的能带、态密度与光学谱都不可信，缺陷能级的位置误差尤其明显。因此缺陷与掺杂结构必须先作几何优化，再在优化构型上计算性质。软件的CASTEP Calculation面板中，Task选择Geometry Optimization即为几何优化，计算完成后生成GeomOpt文件夹，其中保存每一步的构型与最终结构。

优化是否结束，由四个收敛判据共同决定：体系总能量的变化、原子所受最大力、晶胞所受最大应力、原子最大位移。四项全部小于设定阈值才判定收敛。CASTEP的Fine精度下，四项阈值分别约为1×10⁻⁵eV/atom、0.03eV/Å、0.05GPa、1×10⁻³Å，具体数值以当前版本软件的默认设置为准。判据未满足而迭代次数用尽时，任务会以未收敛状态结束，此时应增大迭代步数上限或放宽精度后重新计算，不能把未收敛的构型当作结果使用。

k点网格影响优化的精度。k点越密，布里渊区积分越准确，原子受力也越可靠，代价是计算时间成倍增加。对含数十个原子的超胞，取较稀的k点网格即可，因为超胞的倒格子体积小，少量k点已能覆盖主要区域。

4.4　光学性质的计算原理

光在晶体中的传播由复介电函数描述，写作

ε(ω) = ε1(ω) + i ε2(ω)

虚部ε2描述吸收，由价带占据态到导带空态的跃迁矩阵元求和得到，其大小取决于两态之间的能量差与跃迁概率；实部ε1描述色散，由ε2经Kramers-Kronig变换得到，两者不是独立的物理量。由复介电函数可进一步求出吸收系数

α(ω) = (√2 ω / c) · [ (ε1² + ε2²)1/2 − ε1 ]1/2

式中ω为角频率，c为光速。也可用消光系数k表示：α = 2ωk/c = 4πk/λ。软件在Optical properties一栏中同时给出介电函数的实部、虚部、折射率、消光系数、反射率与吸收系数，本实验只取吸收系数一项。

4.5　吸收边与本征吸收

当光子能量大于禁带宽度时，价带电子可以吸收光子跃迁到导带，形成本征吸收。吸收边即吸收系数开始明显上升的位置，其对应的光子能量近似等于禁带宽度。直接带隙材料的跃迁不需要声子参与，吸收系数在吸收边附近按平方根规律上升，写作α ∝ (hν − Eg)1/2；间接带隙材料的跃迁必须借助声子满足动量守恒，吸收系数按平方规律上升，写作α ∝ (hν − Eg ∓ Ep)2，其中Ep为声子能量。平方规律使间接带隙材料的吸收边明显平缓，这是硅与砷化镓在吸收谱上的一个基本差别。

由吸收边读取带隙时，须把纵轴换成吸收系数的平方或平方根再作线性外推，直接取曲线起翘点会引入较大误差。本实验只要求给出吸收边位置与陡缓的定性描述，定量外推在后续数据处理中完成。

4.6　展宽参数与剪刀算符

光学性质的计算在有限k点网格与有限能带数目下完成，得到的跃迁谱是一系列离散谱线，软件用展宽（Smearing）把它们叠加成连续曲线。展宽增大，曲线平滑、峰高下降、精细结构被抹平；展宽过小，曲线出现锯齿与虚假尖峰。取值应与计算所用k点密度匹配，改变展宽后曲线的峰位基本不动、峰形明显改变，这一点可用于判断曲线形状的变化是否来自参数设置。

剪刀算符（Scissors）用于补偿密度泛函计算对带隙的低估。其做法是把导带整体上移一个能量值，使计算带隙与实验值对齐。剪刀算符只改变能量标尺，不改变波函数与跃迁矩阵元，因此它能使吸收边平移到正确位置，却不能修正吸收边以上的谱形误差。使用剪刀算符须在报告中写明取值与依据，取0表示未作修正。若拿计算值与实验值比较，应说明两者是否施加了同一修正，否则比较没有意义。

4.7　掺杂与缺陷对吸收谱的影响

掺杂改变吸收谱有三条途径，方向并不一致，须结合具体情况判断。其一是费米能级的移动：重掺杂使费米能级进入导带或价带，低能端的跃迁被占位效应阻断，吸收边向高能方向移动，称为Burstein-Moss蓝移。其二是带隙的收窄：高浓度掺杂使杂质带与能带尾重叠，有效带隙减小，吸收边向低能方向移动，称为红移。其三是杂质引入的亚带隙吸收：杂质能级位于禁带之中，能量小于带隙的光子也能引起跃迁，吸收谱在吸收边以下出现吸收尾。三种效应在同一材料中可能同时存在，净效果取决于掺杂浓度与杂质能级的位置。

空位缺陷的作用与掺杂不同。空位在禁带中引入的能级通常较深，其吸收表现为吸收边以下的一段宽吸收带，而不改变本征吸收边的位置。空位还会使周围的键发生明显弛豫，键长分布变宽，吸收边随之变得平缓。比较本征、掺杂、空位三条曲线时，应分别指出吸收边的位置移动与吸收边以下的吸收尾，不要把两者混为一谈。

4.8　偏振设置

光学性质计算需要指定入射光的偏振方向（Polarization）。立方晶系的介电张量为标量，三个主轴方向等价，取默认设置即可。若体系因缺陷或应变而降低了对称性，或计算的是六方、单斜等低对称晶体，不同偏振方向的吸收谱会有差别，此时须分别计算并说明所用方向。本实验的Ge与GaAs属立方晶系，取默认值即可。

五、实验内容与结果

以下按操作顺序给出七个课内任务。前面两步建立掺杂与空位模型，第三步作结构优化，第四步计算光学性质，第五、六步处理并导出数据，第七步整理对比。掺杂的具体操作方法与实验一第四部分相同，此处只写与缺陷建模相关的差别。

5.1　降对称性与替位掺杂（任务1）

  1. 打开实验一建立的超胞文件，另存为新工程，工程名按学号后四位加姓名拼音首字母命名。
  2. 从Build菜单进入Symmetry→Make P1命令，见图1。执行后空间群变为P1，晶胞内原子数不变，但每个格点成为独立位置。
  3. 按实验一的方法完成替位掺杂：选中一个基体原子，用Modify→Constraints或Build→Replace命令把它替换为杂质原子。替换后应确认晶胞内只有一个杂质原子。
  4. 记录被取代原子的编号与分数坐标，写入记录表。若替换后发现杂质原子出现在多个等价位置，说明P1未生效，应退回第二步重做。
观察与记录
  • 记录执行Make P1前后空间群名称的变化，晶胞原子数是否改变。
  • 记录杂质原子的元素、编号与分数坐标，以及超胞的原子总数与对应掺杂浓度。

5.2　空位缺陷（任务2）

  1. 把上一步的文件另存为第二个工程，用于建立空位模型。两种缺陷分别保存，避免相互覆盖。
  2. 在三维显示区选中一个原子，用Delete键或右键菜单中的Delete命令删除，见图2。
  3. 删除后晶胞中出现一个空位，周围原子的成键对象减少一个，见图3。此时结构尚未弛豫，原子仍在原位。
  4. 确认空位只有一个。若删除后出现多个空位，同样说明对称性未降为P1。
观察与记录
  • 记录空位的原子编号与分数坐标，以及空位近邻原子的数目。
  • 观察删除原子后近邻原子的键是否仍显示为完整键长，说明此时结构是否已经弛豫。

5.3　结构优化（任务3）

掺杂与空位结构都必须先优化。以下设置对两个模型相同，分别提交两次计算。

  1. 选中掺杂模型文件，点击CASTEP的Calculation，打开计算面板，见图4。
  2. 在Setup页把Task设为Geometry Optimization，即几何优化，见图4。此处的选择决定后续计算的是优化任务而不是单点能。
  3. 设置交换关联泛函与截断能，见图6。泛函沿用实验二的设置，截断能取软件默认值，改动后须在报告中注明。
  4. 设置k点网格，见图7。超胞的倒格子较小，k点可取较稀的网格；k点越密优化越精确，耗时也越长。
  5. 点击More，设置收敛标准、迭代步数上限与晶胞优化方式，见图5。四项判据全部满足才算收敛，步数上限不宜过小，否则计算可能在未收敛时终止。
  6. 切换到Job Control页，把并行核数设为可用核数的最大值，见图8。超胞计算耗时较长，并行设置直接影响等待时间。
  7. 点击Run提交计算。计算完成后工程中出现GeomOpt文件夹，其中保存最终优化构型，见图9。
  8. 对空位模型重复上述步骤。两个模型的设置应保持一致，便于比较。
观察与记录
  • 记录优化是否收敛，四项判据的最终数值与迭代步数。
  • 比较优化前后缺陷近邻原子的键长，记录弛豫量。空位近邻的弛豫通常比替位更明显。

5.4　光学性质计算（任务4）

  1. 展开GeomOpt文件夹，选中其中的结构文件，点击Calculation，见图10。光学性质计算必须在优化后的构型上进行，不要使用优化前的文件。
  2. 把Task设为Properties，见图10。光学性质与能带、态密度同属性质计算任务，与几何优化、单点能并列。
  3. 切换到Properties页，勾选Optical properties，见图11。能量范围取默认值即可，k点可比优化时更密；光学谱对k点密度敏感，网格过稀会使谱线出现锯齿。
  4. 点击Run提交计算。计算完成后工程中出现Properties文件夹，其中保存光学性质的结果文件，见图12。
观察与记录
  • 确认光学计算所用的结构文件来自GeomOpt文件夹，记下该文件名。
  • 记录本次计算的k点网格，与优化时是否一致。

5.5　吸收谱的分析与输出（任务5）

  1. 计算完成后，在工程目录的Properties文件夹中打开Optics文件，点击CASTEP的Analysis按钮，见图12、图13。
  2. 在列表中选择Optical properties，进入参数设置面板，见图14。先确认Results file一栏指向当前材料的Optics文件。三项参数的作用：Smearing为展宽参数，数值越高曲线细节越少、峰越平滑；Scissors为剪刀算符，用于补足计算带隙与实际带隙的差距，取0表示不作修正；Polarization为偏振方向，立方晶体取默认值即可。
  3. 把Function设为Absorption，即吸收谱，Units选eV，见图14。横轴单位也可选nm，两者的换算关系为λ(nm) = 1240/E(eV)。
  4. 点击Calculate，计算完成后右侧的View按钮由灰变黑，点击即可得到吸收曲线，见图15。
  5. 读出吸收边的位置。吸收边为曲线开始明显上升处，其对应的能量应接近该材料的禁带宽度。同时记录曲线在低能侧是否存在吸收尾。
观察与记录
  • 记录展宽参数与剪刀算符的取值，以及本次使用的横轴单位。
  • 记录吸收边对应的能量或波长，换算成另一种单位后与记录值对照。
  • 记录曲线在吸收边以下是否出现吸收尾，若有，记录其大致能量范围。

5.6　图像数据的导出（任务6）

软件中的曲线不能直接用于定量分析。图中曲线的数值无法读取，坐标范围也由软件自动确定，无法与另一条曲线叠加比较。正确做法是把数据导出为文本文件，在Origin等软件中重新作图。

  1. 保持吸收曲线处于打开且位于最上层的状态，从File菜单选择Export，见图16、图17。
  2. 在弹出的保存对话框中把文件类型选为CSV，指定保存位置与文件名，见图18。文件名应体现材料、缺陷类型与参数设置，便于后续辨认。
  3. 点击保存，得到两列数据，第一列为能量或波长，第二列为吸收系数。
  4. 用记事本或Excel打开导出的文件，确认列数与数值范围正常。若只有一列或数值全为零，说明导出的不是当前曲线，应重新导出。
观察与记录
  • 记录导出文件的名称、列数与数据范围，即能量的最小值和最大值。
  • 确认三组数据（本征、掺杂、空位）各有一个CSV文件，命名能相互区分。

5.7　三种情况的对比与课内检查（任务7）

本实验共需三组数据：未掺杂未含缺陷的本征结构、替位掺杂结构、单空位结构。三组的计算设置应完全一致，否则比较的是设置差异而不是物理差异。整理时按以下顺序进行。

  1. 把三组CSV数据导入同一张图，横轴统一为eV，纵轴统一为吸收系数。横轴单位不一致的曲线不能直接叠加，须先换算。
  2. 比较吸收边的位置。掺杂模型的吸收边可能向高能或低能移动，方向取决于掺杂浓度与杂质能级，须结合4.7节的三条机制说明。
  3. 比较吸收边的陡缓。空位模型的吸收边通常更平缓，原因在于键长分布变宽。
  4. 比较吸收边以下的区域。空位模型的亚带隙吸收通常更明显，这是深能级参与跃迁的结果。
  5. 下课前15分钟接受检查，检查内容包括两个工程文件、优化收敛曲线、三组CSV文件与叠加后的曲线图。
观察与记录
  • 记录三条曲线的吸收边位置，写成表格形式，注明单位。
  • 记录三条曲线在吸收边以下的差异，指出哪一条有明显吸收尾。
  • 写下对差异原因的初步判断，报告中再展开论证。

附录　操作要点与常见问题

一、掺杂后出现多个杂质原子

原因是未执行Make P1，空间群仍按原对称性约束晶胞，软件把单个替换复制到全部等价格点。处理办法是撤销替换，先执行Symmetry→Make P1，再重新替换。若替换已完成且工程已保存，应回到P1之前的文件重做，不要手工逐个删除多余的杂质原子。

二、优化不收敛

先看是四项判据中的哪一项未满足。能量已趋平稳而力仍未达标，多为结构初始畸变过大或截断能偏低；四项都在振荡，多为k点过稀或迭代步数不足。可先增大迭代步数上限，再考虑提高截断能与k点密度。放宽收敛标准只能作为最后手段，且须在报告中注明。

三、光学性质计算的View按钮为灰色

View按钮在点击Calculate之前不可用，计算完成后才由灰变黑。若计算已结束仍为灰色，说明当前打开的不是光学性质结果文件，应确认打开的是Properties文件夹中的Optics文件，而不是GeomOpt中的结构文件。

四、吸收曲线数值异常

曲线全为零或量级明显异常，常见原因有三：剪刀算符取值过大使吸收边移出计算能量范围；计算的能量范围设置过窄，未覆盖带隙以上的区间；光学计算所用的结构未作优化，跃迁矩阵元失真。应逐项核对后重新计算，不要在图中手工裁剪异常段。

五、单位换算

横轴在eV与nm之间切换时按λ(nm) = 1240/E(eV)换算，该式为近似关系，精确计算须用1240除以光子能量并考虑折射率的影响。比较不同材料的曲线时，所有曲线须统一到同一单位，否则横轴数值不可比。

六、关于应变

本实验只做掺杂与缺陷对光吸收的影响。应变对能带结构的影响需另设专题，不在本次实验范围内。
