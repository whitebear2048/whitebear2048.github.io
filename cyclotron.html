回旋共振实验

在恒定磁场 B 中，载流子做回旋运动；当微波频率 ω 与回旋频率 ωc = eB/m* 相等时发生共振吸收。通过共振条件可测定载流子的有效质量 m*，并揭示能带的各向异性。

一、实验原理与共振演示

拖动滑块改变磁场 B、有效质量 m* 与微波频率 f，观察轨道转速与吸收曲线的变化；使当前磁场滑到吸收峰处即发生共振。

实验装置：微波源发出交变电磁场（微波），穿过置于磁场 B 中的半导体样品，右侧探测器测量透射功率。共振时样品强烈吸收微波，透射功率骤降，正是吸收曲线上峰的来源。

二、有效质量的各向异性（以 Si / Ge 为例）

椭球等能面的回旋有效质量随磁场相对晶轴的取向而变。改变 B 与晶轴 [100] 的夹角 θ，观察 mc(θ) 的变化。
m_l=0.98, m_t=0.19 (m₀)
0°
夹角 θ 沿什么方向转（俯视 [100]–[010] 平面）
B 在 [100]–[010] 平面内旋转，青色虚线为垂直 B 的截面方向；θ=0 时 B∥[100]，θ=90° 时 B∥[010]。
B∥[100]：[100] 椭球截面 = 圆（mc=mt），[010] 椭球截面 = 椭圆（mc=√(ml·mt)）；θ 增大两者反转。
垂直 B 的截面切椭球等能面（切在何处 → 圆 / 椭圆）
蓝色截面盘始终垂直于 B，随 B 一起转动；蓝色粗线圈为截面盘与等能椭球的交线，即回旋轨道。
θ=0 时截面⊥椭球长轴 → 交线为圆（mc=mt）；θ=90° 时截面∥长轴 → 交线为椭圆（mc=√(ml·mt)）。
纵向质量 ml = 0.98 m₀ 横向质量 mt = 0.19 m₀ 回旋有效质量 mc(θ) = 0.19 m₀ 对应 fc = 28.0 GHz（B=0.10 T）
关键结论对 Si 的 6 个等价椭球谷，当 B ∥ [100] 时，部分谷轴与 B 平行 → mc = mt ≈ 0.19 m₀；部分谷轴与 B 垂直 → mc = √(ml·mt) ≈ 0.43 m₀。实验中观测到两个不同的共振质量，正是能带各向异性与多谷结构的直接证据。
一般取向：\( m_c(\theta) = \sqrt{\frac{m_l\, m_t^{2}}{m_l\cos^{2}\theta + m_t\sin^{2}\theta}} \)，θ 为 B 与谷轴的夹角。
