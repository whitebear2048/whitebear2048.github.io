k 空间中电子与空穴的运动：实际情况 vs 简化模型

近满带在外电场 ℰ 下的演化：面板一为实际情况（手动逐步，相邻电子逐个跃入空位），面板二为简化模型（点击后自动连续平移）

控制台 面板一与面板二各自独立步进
电场方向：
键盘 → 或 空格 推进面板一，← 后退面板一（两面板互不干扰）
电子 空穴（空态） 标记电子 X / Y / Z / A / B / C / E（沿能带：E → C → B → A → 空穴 → X → Y → Z） 空心浅点 = 可占据的 k 状态格点
面板一 ｜ 实际情况：相邻电子逐个跃入空位 按一次 = 一个相邻电子跃入空位，空穴与该电子交换位置
手动控制 · 点一次，一个电子跃入空位

实际过程：一次只有一个相邻电子跃入空位，空穴出现在这个电子腾出的位置上，因此空穴与该电子的移动方向相反。 第一次点击：最左端的 X 沿能带跃入最右端的空位，二者交换位置；第二次：Y 跃入空穴（即 X 原来的位置）；第三次起 Z 及其余电子依次填入。

面板二 ｜ 简化模型：全体电子同步平移 同一条 E-k 能带；每个电子同时跳向相邻状态，空态随分布同向移动一格
间隔：
点击后自动连续移动

简化模型：把外场下全体电子的整体平移等效为空穴自身移动一格，因此空穴与电子同向。 实际过程中空穴的移动来自相邻电子逐个跃入空位，空穴落在腾空的那一格上，与该电子反向。 两种说法基于同一 E-k 关系，描述的是同一个近满带空位的转移。
